# Excel Pivot Charts Practice

This repository contains data visualization and analysis projects built using **Microsoft Excel**. The primary focus of this repository is practicing data manipulation, data aggregation, and building interactive visual representations using **Pivot Tables** and **Pivot Charts**.

## 📊 Project Overview
The goal of this project is to clean raw datasets and turn them into meaningful summaries. By utilizing Excel's core analytical tools, this repository demonstrates how to transform rows of data into dynamic visual dashboards.

## 🛠️ Features Explored
* **Pivot Tables:** Summarizing large datasets quickly to find trends and patterns.
* **Pivot Charts:** Creating clean, easy-to-read charts (Bar, Line, Pie, etc.) linked directly to pivot summaries.
* **Slicers & Timelines:** Adding interactive filters to slice data by specific categories or dates.
* **Data Cleaning:** Handling blank values, formatting dates, and preparing raw sheets for analysis.
